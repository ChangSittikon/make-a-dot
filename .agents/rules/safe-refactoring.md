# Safe Refactoring & Modularity (การจัดการโค้ดอย่างปลอดภัย)

เพื่อป้องกันปัญหาการแก้ไขโค้ดแล้วไฟล์พัง โครงสร้างเพี้ยน จนต้องเสียเวลาซ่อมแซมเป็นเวลานาน AI เอเจนต์และนักพัฒนาต้องปฏิบัติตามกฎเหล่านี้อย่างเคร่งครัด:

1. **ห้ามแบ็คอัพไฟล์แบบ Manual:** ห้ามสร้างไฟล์สำรองแบบตั้งชื่อเองเช่น `Component_old.tsx` หรือ `Component_backup.tsx` โดยเด็ดขาด เพราะมักจะทำให้เกิดการสับสนของเวอร์ชัน (Version mismatch) ให้ใช้ระบบ **Version Control (Git)** ในการบันทึกสถานะของโค้ดแทน หากโค้ดพังให้ดึงโค้ดจาก Git กลับมา
2. **แยกคอมโพเนนต์เสมอ (Component Modularity):** ไฟล์ React Component ไม่ควรมีขนาดใหญ่เกินไป (หากเกิน 300 บรรทัดควรพิจารณาแยกส่วน) หากหน้านั้นมี Modal หรือ UI หลายส่วนที่ทำงานแยกกัน ให้แตกไฟล์ (Extract) ออกเป็นคอมโพเนนต์ย่อยๆ เช่น แยก `TechUpdatesFeed.tsx` หรือ `SkillsModal.tsx` ออกจาก `AgentHubClient.tsx` เพื่อลดความเสี่ยงที่ Syntax Error แค่จุดเดียวจะทำให้ระบบพังทั้งหน้า
3. **หลีกเลี่ยงการแทนที่โค้ดด้วย Script แบบเดาจุด (Blind String Replacement):** ในการแก้ไขโค้ด เอเจนต์ห้ามใช้วิธีการเขียน Script เพื่อแทนที่คำด้วย `indexOf` หรือ Regular Expression ที่ซับซ้อนและครอบคลุมพื้นที่กว้างๆ เพราะมีโอกาสสูงมากที่โค้ดจะถูกแทรกผิดบรรทัดหรือเกิดโค้ดซ้ำซ้อน (Duplication)
4. **ตรวจสอบการคอมไพล์ทุกครั้ง:** หลังจากการแก้ไขไฟล์สำคัญ จะต้องอ่าน Log ของ Next.js เสมอเพื่อตรวจสอบว่าโค้ดสามารถคอมไพล์ได้ผ่าน 100% หรือไม่ ก่อนจะสรุปงานให้ผู้ใช้ฟัง
