# Strict Git & Refactoring Workflow

ใช้กฎนี้ทุกครั้งที่มีการเขียนโค้ด ปรับแต่งฟังก์ชัน รันสคริปต์แก้ไขไฟล์ หรือส่งมอบงาน เพื่อรักษาเสถียรภาพของโปรเจกต์และรับประกันว่าโค้ดได้รับการสำรองขึ้น GitHub เสมอ

## เมื่อใดที่ต้องบังคับใช้:
- มีการสร้าง แก้ไข หรือสร้างโค้ดใหม่
- รันสคริปต์ที่แก้ไขไฟล์ในเครื่อง
- เมื่อสร้างส่วนประกอบหรือคอมโพเนนต์ย่อยเสร็จสมบูรณ์
- เมื่อสิ้นสุดแต่ละขั้นตอนหรือกำลังจะจบเซสชันการสนทนา

---

## กฎเหล็ก 5 ประการ (Core Directives):

### 1. The "Checkpoint" Rule (Commit ทันทีเมื่อผ่าน)
- **Commit Immediately:** ทันทีที่ฟีเจอร์ทำงานถูกต้อง การรีแฟกเตอร์เสร็จสิ้น หรือสคริปต์แก้ไขไฟล์สำเร็จ ให้รัน `git commit` ทันทีเพื่อบันทึก Checkpoint
- **Git คือการสำรองข้อมูลเดียว:** ห้ามสร้างไฟล์สำรองแบบ Manual เช่น `_old.tsx`, `_backup.tsx` โดยเด็ดขาด ให้ใช้ Git Commit เพื่อบันทึกสถานะ
- **ห้ามสะสมงาน:** ห้ามปล่อยให้การแก้ไขไฟล์ค้างสะสมโดยไม่ commit เป็นเวลานาน

### 2. The "End of Session" Rule (Mandatory Push ขึ้น GitHub)
- เมื่องานย่อยสำเร็จ หรือรอบการทำงานกำลังจะเสร็จสิ้น **ต้องสรุป Commit ที่ทำไป และรันคำสั่ง `git push origin main` ขึ้นไปยัง Remote Repository (GitHub) เสมอ**
- ห้ามปล่อยให้โค้ดค้างอยู่ใน Local นานข้ามวันโดยไม่ดันขึ้น Cloud เด็ดขาด

### 3. Safe Refactoring (File Size Limits & Modularity)
- **Hard Limit 300 บรรทัด:** ห้ามปล่อยให้ไฟล์ Component หรือ Page มีขนาดใหญ่เกินไป (เช่น เกิน 300 บรรทัด) ต้องแตกเป็นคอมโพเนนต์ย่อย แยกแท็บ (Tabs) แยกประเภท (Types) และแยกข้อมูลตั้งต้น (Constants) ทันที
- **ห้ามใช้ Script ตัดแปะแบบสุ่มเสี่ยง:** ห้ามใช้คำสั่ง Shell Script (PowerShell / Bash) ตัดและแทนที่โค้ดทีละร้อยบรรทัดแบบ Blind Replacement ต้องใช้เครื่องมือ Patching ที่ระบุบรรทัดชัดเจนและผ่านการตรวจสอบ Type-check เสมอ

### 4. Interpretation of Rules
- ให้ตีความกฎด้าน Git ไปในทาง "ความปลอดภัยสูงสุดและการอนุรักษ์ข้อมูล" เสมอ หากมีข้อความระบุให้ใช้ Git บันทึกสถานะ ย่อมหมายถึงการ Commit อย่างสม่ำเสมอและ Push ขึ้น GitHub เสมอ

### 5. Security & Database Isolation
- ห้ามฝัง Personal Access Token (PAT) ใน Git Remote URL หรือ git config
- ห้าม Track ไฟล์ฐานข้อมูล Local (`prisma/*.db`, `*.db-journal`) ลงใน Git เด็ดขาด
