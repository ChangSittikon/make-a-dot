# Verify Before Speak (ตรวจสอบก่อนรายงานเสมอ)

นี่คือกฎเหล็กสำหรับ AI เอเจนต์ทุกคนในโปรเจคนี้ เพื่อป้องกันปัญหา "AI แจ้งว่าแก้แล้ว แต่ผู้ใช้รีเฟรชแล้วไม่เห็น หรือเว็บพัง"

1. **บังคับเช็ค Log ก่อนตอบ:** ทุกครั้งที่มีการบันทึกไฟล์ (Save file) หรือแก้ไขโค้ดใดๆ AI จะต้องรันคำสั่งเช็ค Log ของ Next.js (หรือระบบที่เกี่ยวข้อง) เสมอ และต้องแน่ใจว่าระบบตอบกลับมาว่า `Compiled in...` หรือไม่มี Error ก่อนถึงจะพิมพ์ตอบกลับผู้ใช้ได้
2. **ห้ามเดาว่าโค้ดผ่าน:** ห้ามทึกทักเอาเองว่า "โค้ดน่าจะทำงานได้" หากยังไม่ได้ตรวจสอบผลลัพธ์ผ่าน Terminal
3. **เลิกใช้ Blind Code Replacement:** ในการแก้ไขไฟล์ที่มีอยู่แล้ว ห้ามใช้ Script กะเกณฑ์เพื่อ `replace` ข้อความแบบหยาบๆ ให้ใช้เครื่องมือแก้ไขโค้ดที่เจาะจงบรรทัดอย่างแม่นยำ (Line-by-line patching) เพื่อป้องกันโค้ดซ้ำซ้อนหรือโครงสร้างไฟล์พัง
4. **หากพบ Error ห้ามฟ้องผู้ใช้ทันที:** หากแก้โค้ดแล้วคอมไพล์พัง ให้ AI พยายามวิเคราะห์และแก้ Error นั้นด้วยตัวเองก่อน (Silent Fix) หากพยายามเกิน 3 ครั้งแล้วยังไม่สำเร็จ ค่อยแจ้งให้ผู้ใช้ทราบพร้อมอธิบายสาเหตุ
