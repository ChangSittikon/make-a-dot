# MAKE A DOT - กฎสถาปัตยกรรมระบบ (Core Architecture Rules)

## 1. ข้อมูลต้องมาจากแหล่งเดียว (Single Source of Truth)
- **กฎ**: พฤติกรรมของ AI, การตั้งค่าแอปพลิเคชัน และการเปิด-ปิดฟีเจอร์ต่างๆ จะต้องดึงมาจากค่าที่ตั้งไว้ในฐานข้อมูล (เช่น SystemConfig) เท่านั้น
- **ข้อห้าม**: ห้ามแอบเขียนโค้ดฝังค่าตายตัว (Hardcode) ไว้ในระบบหลังบ้านเพียงเพื่อแก้ปัญหาเฉพาะหน้าเด็ดขาด
- **เหตุผล**: เพื่อให้ระบบตอบสนองตามที่แอดมินตั้งค่าผ่านหน้า UI เสมอ 100% การทำ Hardcode จะทำให้หน้าแอดมินพังและเกิดบั๊กที่ตามแก้ได้ยาก

## 2. ระบบสลับโมเดลสำรอง (Model Fallback Logic)
- ฟีเจอร์ที่เกี่ยวกับการสร้างข้อมูลด้วย AI ต้องมีการเขียนระบบสลับโมเดลสำรองที่ดึงข้อมูล fallbackModels จากฐานข้อมูลเสมอ
- ห้ามใส่รายชื่อโมเดลปลอมหรือไม่รองรับลงไปในระบบสำรอง ต้องแน่ใจว่าโมเดลนั้นรองรับ API ที่เรียกใช้งาน (เช่น การทำ Structured Outputs ต้องใช้รุ่น 1.5-flash หรือ 1.5-pro เป็นอย่างน้อย)
