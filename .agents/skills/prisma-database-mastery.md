# Prisma Database Mastery

ทักษะนี้มีไว้เพื่อให้ AI เอเจนต์ทำงานกับฐานข้อมูล Prisma ได้อย่างสมบูรณ์แบบตั้งแต่ต้นจนจบ เมื่อมีการร้องขอให้เพิ่มหรือแก้ไขตารางใน Database ให้ทำตามขั้นตอนเหล่านี้:

1. **แก้ไขไฟล์ `prisma/schema.prisma`:** อัปเดต Model ให้ตรงกับความต้องการของระบบ
2. **รันคำสั่ง Push:** หลังจากเซฟไฟล์แล้ว ให้รันคำสั่ง `npx prisma db push` บน Terminal เสมอ เพื่อซิงค์โครงสร้างไปยัง SQLite
3. **รันคำสั่ง Generate:** รันคำสั่ง `npx prisma generate` เพื่ออัปเดต Prisma Client Types
4. **อัปเดตไฟล์ Seed (ถ้าจำเป็น):** หากตารางที่เพิ่งสร้างจำเป็นต้องมีข้อมูลตั้งต้น (Mock Data) ให้เอเจนต์ทำการสร้างโค้ดสำหรับสร้างข้อมูลลงในสคริปต์ Seed แล้วแจ้งผู้ใช้

**ข้อควรระวัง:** ห้ามแนะนำให้ผู้ใช้รันคำสั่งเอง (Proactive Execution) เอเจนต์จะต้องเป็นคนรันคำสั่ง `npx prisma db push` ให้สำเร็จก่อนรายงานผลเสมอ
